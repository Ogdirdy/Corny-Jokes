# 🌽 Corny Jokes Website

A fun and simple website built to deliver the corniest jokes on the internet.  
Whether you love dad jokes, cheesy punchlines, or cringe-worthy humor, this site is guaranteed to make you laugh... or at least groan.

## 🚀 Features
- Random corny jokes generator
- Clean and responsive design
- Easy-to-use interface
- New joke button for endless laughs
- Lightweight and fast

## 🛠️ Built With
- HTML5
- CSS

## 📂 Project Structure
```
corny-jokes/
│── index.html
│── style.css
│── assets/
└── README.md
```

## 🎯 Purpose
This project was created for fun and to practice front-end web development skills while building something entertaining.

## ▶️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Ogdirdy/corny-jokes.git
   ```

2. Open the project folder:
   ```bash
   cd corny-jokes
   ```

3. Open `index.html` in your browser.
